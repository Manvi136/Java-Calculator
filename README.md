# 🧮 Java Calculator

A calculator application built in **two versions** to demonstrate both Java programming and frontend web development skills.

## 🌐 Live Demo

**Try it here:** https://manvi136.github.io/Calculator/

---

## 📖 About the Project

This repository contains two implementations of a calculator:

* ☕ **Java Version** – A console-based calculator built using Java.
* 🌐 **Web Version** – A responsive calculator built using HTML, CSS, and JavaScript that runs directly in the browser.

---

## ✨ Features

### Java Calculator

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero handling
* User input using `Scanner`
* `switch` statement implementation

### Web Calculator

* Responsive user interface
* Basic arithmetic operations
* Decimal support
* Percentage operation
* Clear (AC) button
* Backspace (⌫) button
* Error handling

## 🚀 Running the Project

### Web Version

Simply visit the live demo:

**https://manvi136.github.io/Java-Calculator/**

Or run locally by opening `index.html` in your browser.

### Java Version

1. Open the project in your preferred Java IDE.
2. Run `Calculator.java`.
3. Follow the prompts in the console.
